# AI 对话笔记

把 Claude、ChatGPT、Gemini、DeepSeek、Kimi、豆包等网页上的 AI 对话变成思源笔记，并按 claude.ai 的原生样式显示：提问是右侧的暖色气泡，回答是衬线正文，代码块、表格、公式都保留。

## 功能

### 粘贴即成对话

在 AI 网页上选中对话（可以连续选中多轮）复制，回到思源文档里直接 `Ctrl+V`。插件识别到提问和回答后，会把每一轮转成一个带角色属性的超级块：

- 识别网页结构：Claude、ChatGPT、Gemini、Kimi、豆包、DeepSeek
- 识别文本里的说话人标签：`You said:` / `ChatGPT said:` / `User:` / `Assistant:` / `Human:` / `Claude:` / `用户：` / `我：` / `AI：` / `问：` / `答：` 等
- 没有识别到对话时不做任何处理，保持思源默认的粘贴行为
- 在代码块里粘贴时不会接管

只复制了一段回答？用命令面板里的「以对话格式粘贴」，整段会按回答样式插入。也可以在块标菜单中选择「对话样式 - 设为提问 / 设为回答 / 设为思考过程 / 取消对话样式」手动调整。

### 导入本地聊天记录

点击顶栏的对话图标，或在命令面板中执行「导入聊天记录」，选择或拖入文件：

| 来源 | 文件 |
| --- | --- |
| Claude | 设置 - 隐私 - 导出数据 得到的 `.zip`，或其中的 `conversations.json` |
| ChatGPT | 设置 - 数据控制 - 导出数据 得到的 `.zip`，或其中的 `conversations.json` |
| DeepSeek | 导出数据得到的 `conversations.json` |
| 通用 | `[{ "role": "user", "content": "..." }]` 或 `{ "messages": [...] }` 格式的 JSON |
| 其他 | 带说话人标签的 `.md` / `.txt`，网页另存为的 `.html` |

每个对话导入为一篇文档，放在 `笔记本/<来源>/<标题>` 下（来源不明的放在「其他」），并记录原始 ID；重复导入同一个文件会自动跳过已经导入过的对话。默认不导入思考过程，可在导入对话框或插件设置中打开。

### 本地模式（默认开启）

- 关闭思源的云端同步和更新包自动下载
- 隐藏顶栏的同步按钮和订阅入口
- 插件设置中显示笔记的存储目录（思源工作空间），桌面版可直接打开

思源的笔记本来就保存在本地工作空间目录中。更换存储目录：桌面版使用 左上角主菜单 - 工作空间 - 新建 / 打开；Docker 部署修改 `.env` 中的 `SIYUAN_WORKSPACE`。

## 设置

| 设置项 | 说明 |
| --- | --- |
| 本地模式 | 默认开启 |
| 粘贴时自动识别对话 | 默认开启 |
| 导入到的笔记本 | 默认「AI 对话」，不存在时自动创建 |
| 导入思考过程 | 默认关闭 |

## 搭配主题

对话块的样式由插件提供，适用于任意主题。搭配同仓库的「Claude 风格」主题（`claude-style`）时，界面整体也会变成 Claude 的暖白配色和字体。
